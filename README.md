# SkillSwap

A modern **job marketplace web app** built with **Next.js 15**, where job seekers and employers connect seamlessly.  
Users can explore job listings, save opportunities, and track applications, while employers manage postings and candidates—all through a clean, responsive UI.

## Features

- 🔍 **Job Filtering** – Discover jobs tailored to your skills.
- 💾 **Save & Manage Applications** – Bookmark jobs, track application status.
- ⚡ **Responsive Design** – Optimized for desktop, tablet, and mobile.
- 💡 **Real-time Data** – Powered by Next.js App Router & server actions.

## Tech Stack

- **Frontend & Backend**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL + Supabase
- **Deployment**: Vercel
